## 11. Cleanup Rules Going Forward

A future deletion pass must satisfy **all** of these before removing even a documentation-only artifact:

1. identify the permanent successor/authority;
2. search live repository references to the exact path/basename;
3. prove no current prompt, handoff, roadmap, branch disposition, accepted audit, research program, or historical register names it as required evidence;
4. fold any unique source mapping, rationale, citations, or provenance needed by the successor;
5. validate links/references in a real repository checkout;
6. delete only a small coherent batch;
7. commit the deletion separately enough that historical loss is reviewable.

Filename age, `tmp-`, `queued-`, `held-`, `prestage`, or an obsolete version number is never sufficient by itself.
