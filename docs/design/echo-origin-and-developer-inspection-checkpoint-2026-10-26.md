# Echo Origin and Developer Inspection Checkpoint

Date: 2026-10-26. Source: `master` `a596112acf3945f2bf7c625e943f2511d12aa710`; isolated source commit `979ce791`. Status: `ECHO_ORIGIN_REPAIR_VERIFIED; DEV_INSPECTION_AVAILABLE; MUTATING_DEV_COMMANDS_HELD`. Game `0.1.1-prealpha`; no deployment.

## Owner decision and implementation

New creator snapshots persist the exact creation attributes and per-skill ranks in `progression.originBaseline`. Echo uses **current positive growth above those values**, with the existing normalization, weights and level formula. A starter skill remains effective for actions, but its creation tranche contributes no Echo, knowledge Echo or diversity. A later legitimate rank or attribute increase contributes only its growth tranche. Recalculation is pure and idempotent; reducing a rank/attribute can reduce present Echo, and regaining it restores the same value rather than adding an event reward. This chooses present earned capability over an append-only event ledger. The existing persisted progression and Ashen Reef validation accept the optional baseline; older snapshots without one keep their prior formula because their original creation values cannot be inferred safely. Existing browser data was not reset.

Actual noncombat, combat and survey skill-gain callers update the same skill ranks and recompute through `resolvePlayerEchoProgression`; they retain their gain policy and provenance. There is currently no Dev skill/attribute mutation command. Future QA grants must be confined to a marked isolated campaign and must not be passed through these ordinary earned-growth callers as legitimate lineage evidence.

The top bar now shows a default-visible `Dev` button. Its popup has independent native disclosure sections for Items, Time & Calendar, Weather & Climate, Spawns & Encounters and Diagnostics. It opens from the real `InGameShell`, closes on outside pointer/Escape, and returns focus to its trigger after Escape or Close. The menu is responsive through a viewport-bounded overlay. It reads the selected campaign's clock, snapshot version, session revision, Echo and a deterministic profile-eligibility inspection. The inspector shares region, location, habitat and hazard checks with the spawn resolver and reports the seeded spawn-rate roll separately. Missing authored context fails closed; time, season and weather filters are explicitly unsupported. It never admits an encounter.

## Deferred command contract

- **Time:** `gameplayLoop.advanceSnapshotClock` is private and used by distinct activity/rest/travel actions. It advances clock, body and resources, but no accepted generic idle-watch command defines world, quest, economy and QA publication effects. No `Advance` button is exposed yet. The next owner slice must specify elapsed-watch semantics, QA campaign isolation, idempotent request/revision receipt and full Save/readback before offering 1 watch, N watches or N days.
- **Items:** PR #20 supplies an unactivated native gear owner. A Dev grant must wait for its caller/current-format Save cutover, then use that one owner for canonical items, unique instances, durability, bag/overflow/worn location, stale/retry protection and QA provenance. No current item was granted.
- **Weather:** current `WorldState.weatherState` is an untyped empty record and climate is informational. A future typed scenario override should bind `scenarioId`, `campaignId`, `regionId`, authored `conditionId`, intensity, `startsAtTick`, `expiresAtTick`, `requestId`, source `dev`, precedence and a clear command. It must validate region/condition, publish atomically and never imply environmental effects until those owners consume it. This contract is a proposed next design gate, not an active schema.
- **Spawns:** this pass inspects actual current context only. Authored daypart/season/weather predicates, seeded QA context selection and an encounter-admission command remain separate world-owner work. World-Stray's narrative unlock/boon and founder balance remain deferred.
