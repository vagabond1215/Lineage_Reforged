## Source inventory: do not invent options

**Playable lineages:** `apps/rpg-ui/src/game-shell/characterCreationCatalog.ts` defines 10 playable IDs with their own color palettes and lineage-card art: Human, Dwarf, Gnome, Halfling, Elf, Dark Elf, Half Troll, Half Orc, Half Goblin and Half Merfolk. `getLineageIdentityCatalog(lineageId)` derives current legal sorted `skinToneOptions`, `hairColorOptions`, `eyeColorOptions` from a lineage seed and additive palette expansion. The complete current sets have **18 skin, 27 hair and 18 eye colors for each lineage**. Do not substitute a universal human palette, invent color IDs, assume the same label/hex is valid across lineages, or let changing ancestry preserve an illegal color ID.

**Offline preview selection:** to keep this design-review form reasonably compact, it exposes **14/18/14 actual source-option subsets** per lineage, each with its actual name+color pair. Production source implementation must continue to use the **complete** `getLineageIdentityCatalog` response, not copy the standalone subset/hexes as runtime authority. Source `characterCreationForm.ts` `skinToneId`/`hairColorId`/`eyeColorId` and original legality checks remain authoritative. Current source palette options are IDs with labels and swatch metadata; the HTML demo uses label/hex pairs only and is not Save-valid serialization.

**World geography:** `packages/content/base/world/regions.json` has 41 records, of which **five `continent` and four `island_system`** records are top-level creator choices, **28 `subregion`** records are children, and **four `ocean`** records are not creator starting continents. `packages/content/base/world/settlements.json` currently contains **88 named settlement records**, each with a canonical `regionId`, `macroRegionId`, site class, environment/settlement context, population/economy and start-access-related properties. Example source correction: **Highcrown is in The Sapphire Rivers of Valtherion**, not The Crownlands. `region.starfall_isle` contains Starfall Port, Harbormast Quay and Foammarket Ferry. No settlement should appear under the wrong ancestor.

**Art coverage:** `worldSelectionCatalog.ts` references pinned `characterCreatorAssetUrl.ts` source commit `712982fbf72b158280df0ac89dc903d3b1832ab4`. Source tree has matching named PNG images for **all 9 macro choices, 13 of 28 subregion choices, and 69 of 88 settlements**. Other images are **not generated or approved**. The [100-file named archive manifest](character-creator-geography-art-retention-manifest-2026-11-17.json) remains the source retention witness; do not move/replace/delete pinned PNGs merely to fill blank cards. In an offline HTML preview, source image URLs may be network-inaccessible: a neutral monogram fallback indicates missing loading, not new canonical art. A location with no historical bitmap uses `Artwork pending` without a false neighboring image.

**Correct production option owners:** use `getWorldContinentOptions`, `getWorldRegionOptions`, `getWorldSettlementOptions` and `resolveWorldSelection` plus actual signed-in World, content manifest and `startAccess` validations. Do not use the name-only mock arrays or mark all 88 as **playable spawn sites**. Any underground or underwater settlement also needs the actual supported scene/lineage/mode/entry owner. Content list breadth is not proof of first-publication readiness.
