# Native-v3 Soundings turn-in retained payment contract

Date: 2026-11-06. Scope: isolated child of draft #69, Game `0.1.1-prealpha`. Both staging publication and selected atomic activation remain held.

The authored Soundings of Ashen Reef contract pays exactly five gold once at the Starfall Harbormaster's Office after four ordered survey shifts. It completes the one quest, clears its tracking, closes its operation, changes activity, and adds one completion Chronicle and notification. It changes no gear, inventory, resource, skill or reputation owner. The v2 turn-in command and witness require the v2 survey authority and cannot admit a native-v3 campaign.

Native-v3 completion therefore has its own versioned, single-result record in the v3 snapshot. The result names the immutable account/campaign/continuity, source artifact/publication/revision, request/result/projection IDs, four-stage survey fingerprint, tick, gold and presentation state before completion. The selected caller obtains those facts from the exact ready account slot and requires matching account revision and source address. A request is accepted only with a completed native ledger, active quest, Starfall location and a saved, at-head session. A repeated request returns the retained result without another payment; conflicting or stale requests leave the pair unchanged.

The existing version-8 campaign store is the durable witness owner. For the first completion it reads the exact predecessor artifact inside the publication transaction, verifies the survey chain, re-executes the native turn-in command from that source and compares the published completion after the normal Save-time achievement projection. On readback it performs the same retained-source replay. Later artifacts must retain the exact completion record and anchor to the unique first completion artifact; removal or modification fails. Interrupted publication remains under the existing atomic campaign/account transaction and pending-consumer recovery. No new browser store, save epoch, v2 Soundings witness or parallel item/currency owner is created.

The native snapshot validator checks record structure and current completion projections. Exact first-result replay and historical source identity require the retained store; a standalone JSON snapshot is not a durable payment witness. The production v2 completion owner and historical witnesses remain unchanged.
