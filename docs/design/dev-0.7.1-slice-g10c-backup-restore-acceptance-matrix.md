## Package and failure boundaries

One coherent package: epoch owner archive export/preflight/atomic import, selected account-picker import and Settings export, and focused disposable browser evidence. No schema upgrade, credential algorithm change, save-intent request IDs, migration from legacy, pruning, G10D eviction, deployment or held-branch integration. Export is a consistent read transaction over all 14 exact stores, with archive format/schema/source identity, per-family counts and SHA-256 digest plus whole-payload digest. The portable file includes password verifier records and sensitive game state; show the warning before download and file selection. No verifier or raw row contents in notices, errors, previews or logs.

Input cap: 64 MiB UTF-8 and 64 MiB file size. G10B.5's measured representative JSON graph was about 10 MiB pessimistic UTF-16, so this is a bounded G10C safety cap, not a G10D long-run capacity finding. Reject larger archives before parse or mutation. Revisit the cap only in G10D with measured long-run growth.
