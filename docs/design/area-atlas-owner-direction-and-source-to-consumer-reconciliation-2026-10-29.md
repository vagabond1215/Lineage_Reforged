## 2. Chosen destination hierarchy (product intent, not selected implementation)

```text
Authenticated campaign start / resume
    → CURRENT AREA (the immediate observed gameplay scene; one default surface)
      current place heading + actual condition + one meaningful immediate decision
      exact owner-backed Explore / candidate / combat / Travel / eligible Rest links
      current activity/quest context + accepted recent outcomes + safe cross-links
      domain controls: Character, Inventory, Activity, Quests, Codex, Chronicle, etc.

CODEX → ATLAS
    known/disclosed geographic reference, region/settlement/site hierarchy,
    route and place knowledge, map/list when genuinely grounded, inspection
    → link to Current Area / request actual travel preview through owning UI
    ≠ independently issuing travel by inspecting a map
```

- A route implementation may **reuse the historical internal `world` TabId as an adapter** or safely rename it to `area` after caller/deep-link/keyboard tests. The *visible intended product* is Current Area as default, not a second persistent World root/browser, not an extra Home and **not** World sibling Area+Atlas navigation.
- Re-entering by deselecting a domain or using a clear return-to-place affordance should show the same Area screen. Global left rail/top bar must stay responsive; portrait may use the existing horizontal domain strip. The internal `TabId | null` representation is implementation detail; null currently renders a blank panel, so it must not be assumed functional before code.
- **Codex Atlas** is one reference surface. The older World map's broad geography and region/settlement/trade-route *reference* material may move or be linked only as supported by actual player-known data. Local travel and selected destinations remain distinct; a map point is not an authorized teleport.
- Current `Activity`/`Quests`/`Inventory` panels keep their distinct command/data owners. Area may point to them or invoke already selected owner actions through the same caller, but cannot create a duplicate quest, item or market transaction system.
- The selected source currently launches Character and retains a World section browser. That is **a source-versus-target delta**, not a license to state Area has already been activated or that the game currently loads there.
