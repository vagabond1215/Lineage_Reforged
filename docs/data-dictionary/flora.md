# Flora

Core fields:

- identity: `id`, `slug`, `name`, `type`
- lifecycle: annual/biennial/perennial and growth stage constraints
- harvest: active/passive modes, yield caps, regrowth behavior
- ecology links: habitat and biome references

Slug guidance:

- use lowercase snake case for `slug` (example: `blackberry`)
- keep names broad and gameplay-meaningful (example: `Blackberry`, not region-specific variants)
