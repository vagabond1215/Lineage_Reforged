# Minerals

Core fields:

- identity: `id`, `slug`, `name`, optional `aliases`, tier
- deposit model: node/vein/lode/seam/pocket forms
- extraction model: manual vs infrastructure extraction
- economy link: source for tool, construction, and crafting pipelines

Slug guidance:

- canonical slugs represent the gameplay resource (`iron_ore`, `copper_ore`, `salt`)
- use `aliases` only for alternate player-facing labels, not location-specific variants
