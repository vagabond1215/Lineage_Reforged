### November 21 earlier palette clipping and near-duplicate correction (historical review)

- **Observed problem:** The previous HSV adjustment used `min(1, anchor.v * (0.25 + brightness * 0.0115))`, which clipped several light tones to **white** at higher Brightness and left deep colors nearly black. Selecting sixteen anchors by evenly sampling a hue-sorted source list also placed near-indistinguishable choices beside one another.
