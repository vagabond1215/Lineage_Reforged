## Historical Overview

### Added

* TypeScript-first simulation scaffold with content, schemas, engines, tools, tests, and docs
* RPG UI launcher, character creator, in-game shell, local account, save, Legacy, Chronicle, and achievement surfaces
* Canonical world, ecology, settlement, travel, economy, workplace, quest, player progression, spell, ability, item, and combat catalogs
* Content linting, DB build, scenario runner, schema validation, and focused unit/integration/simulation test coverage

### Changed

* Player progression moved from placeholder seed data to canonical skills, spells, trials, effects, and item-use models
* Economy and quest systems expanded into workplace tiers, infrastructure gates, market context, production variants, and guild-driven offers
* Launcher, creator, and runtime UI moved toward shared shell chrome, semantic theme tokens, asset-backed selection cards, and improved light-mode contrast
* Account progression shifted toward Legacy, Chronicles, run archival, achievements, preparation choices, Renown scaffolding, and estate previews
* Combat foundation added action aliases, damage previews, ranged/melee/armor/shield handling, monster evasion, and equipment use profiles

### Fixed

* Broad content-lint blocker chain cleared across spell contracts, Echo rules, ecology profiles, travel networks, settlements, quests, and item references
* World geography consistency improved across island subregions, dependent settlements, maritime lanes, biome/flora/fauna references, and demographics
* Runtime and UI stability improved through save/load, launcher, theme, creator image, top-bar, body-state, and bridge-file fixes
* Generated and vendor artifact paths marked ignored for future repository hygiene

### Notes

* Historical entries are backfilled from repository docs and backlog notes, not formal release tags
